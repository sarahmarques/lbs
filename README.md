# London Business School

This projects uses the following technologies:

- `ContentFul`
- `Next.js`
- `Typescript`
- `SCSS`
- `Cypress`
- `Jest`

## ⚒️ Working Node Version
```javascript
16.7.0
```

## ⚒️ Installation
```javascript
npm install
```


## 📜 Scripts

- Start client on [http://localhost:3000/](http://localhost:3000/)

```javascript
npm run dev
```

- Start Storybook

```javascript
npm run storybook
```

- Run your unit test(s)

```javascript
npm run test
```

- Static site generator

```javascript
npm run export
```
